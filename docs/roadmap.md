# v1.1 Roadmap

## Web 界面深化

- 增加规则编辑器和 dryrun 预览，提交前显示字段、容差和影响范围。
- 增加复核队列、批量筛选、权限角色和复核操作审计。
- 报告下载支持异步任务、历史版本比较和浏览器内预览。

## 分布式执行

- 把执行计划拆成可恢复任务，支持队列、工作节点和租约超时。
- 统一任务幂等键，避免重复写入历史和重复发送通知。
- 增加节点健康检查、失败重试策略和执行指标导出。

## 更多文件格式

- 增加 XML、ODS 和常见数据库查询结果读取器。
- 保持统一 Table 接口、流式读取和字段类型映射。
- 为每种格式补充编码、日期序列号、空值和大文件基准场景。

Roadmap 只描述后续方向，不改变 v1.0.1 的稳定接口。
